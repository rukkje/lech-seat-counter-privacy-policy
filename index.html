Lech Ticket Counter

Polityka prywatności

Data wejścia w życie: 3 października 2026

Lech Ticket Counter to niezależne, nieoficjalne rozszerzenie do Chrome służące do prezentowania informacji o dostępności biletów na mecze Lecha Poznań bezpośrednio na stronie sprzedaży biletów.

Jakie dane są przetwarzane?

Rozszerzenie odczytuje wyłącznie dane dostępne na stronie bilety.lechpoznan.pl, które są potrzebne do działania licznika. Mogą to być między innymi:

  • nazwa i data meczu,
  • informacje o sektorach i trybunach,
  • informacje o miejscach i ich dostępności.

W jaki sposób dane są używane?

Dane są wykorzystywane wyłącznie do obliczania i wyświetlania statystyk dotyczących dostępności biletów, puli sprzedażowej, niedostępnych miejsc, statystyk dla trybun oraz czasu pozostałego do meczu.

Przetwarzanie lokalne

Dane są przetwarzane lokalnie w przeglądarce użytkownika. Rozszerzenie nie wysyła tych danych na serwery dewelopera i nie przekazuje ich podmiotom trzecim.

Dane, których rozszerzenie nie zbiera

Rozszerzenie nie zbiera ani nie przechowuje:

  • danych osobowych umożliwiających identyfikację użytkownika,
  • danych logowania ani haseł,
  • danych finansowych ani informacji o płatnościach,
  • lokalizacji użytkownika,
  • historii przeglądania,
  • prywatnej komunikacji,
  • danych dotyczących aktywności użytkownika poza funkcjami samego rozszerzenia.

Schowek

Funkcja „Kopiuj informacje” zapisuje wygenerowane statystyki do schowka wyłącznie po kliknięciu przycisku przez użytkownika. Rozszerzenie nie odczytuje zawartości schowka.

Analityka, reklamy i sprzedaż danych

Rozszerzenie nie korzysta z narzędzi analitycznych ani reklamowych, nie sprzedaje danych użytkowników i nie wykorzystuje danych do profilowania.

Zmiany polityki prywatności

Jeśli sposób działania rozszerzenia lub zakres przetwarzanych danych ulegnie zmianie, niniejsza polityka prywatności zostanie odpowiednio zaktualizowana.

Kontakt

Informacje kontaktowe do dewelopera są dostępne na stronie rozszerzenia w Chrome Web Store.

Privacy Policy

Effective date: October 3, 2026

Lech Ticket Counter is an independent, unofficial Chrome extension that displays ticket availability information for Lech Poznań matches directly on the ticket sales website.

What data is processed?

The extension reads only data available on bilety.lechpoznan.pl that is required for the ticket counter to work. This may include:

  • match name and date,
  • stand and sector information,
  • seat information and availability status.

How is the data used?

The data is used solely to calculate and display ticket availability statistics, the estimated sales pool, unavailable seats, stand-by-stand statistics, and the time remaining until the match.

Local processing

Data is processed locally in the user's browser. The extension does not send this data to the developer's servers and does not share it with third parties.

Data the extension does not collect

The extension does not collect or store:

  • personally identifiable information,
  • login credentials or passwords,
  • financial or payment information,
  • user location,
  • browsing history,
  • private communications,
  • user activity outside the extension's own features.

Clipboard

The “Copy info” feature writes generated ticket statistics to the clipboard only after the user clicks the button. The extension does not read clipboard contents.

Analytics, advertising, and data sales

The extension does not use analytics or advertising services, does not sell user data, and does not use user data for profiling.

Changes to this privacy policy

If the extension's functionality or data processing practices change, this privacy policy will be updated accordingly.

Contact

Developer contact information is available on the extension's Chrome Web Store listing.
